# v0 프롬프트 — UI 디자인 일괄 적용 (#111)

v0(v0.app)에 넘길 프롬프트와 사용 절차. 디자인 언어가 화면마다 어긋나지 않도록
**4개 화면을 한 채팅에서 한 번에 생성**하고, 코드 이식은 Step a→d로 나눈다.

v0는 Free 플랜(월 $5 크레딧, v0 자체 모델)으로 쓴다. 초기 생성 1회에 수정 서너 턴이
한계라서, 후속 턴에서 고칠 만한 내용은 전부 초기 프롬프트에 미리 넣어 한 번에 뽑는다.
(2026-09-07 개정: 후속 프롬프트 3건 합침, 샘플 데이터·산출물 경로·미리보기 제약 추가,
지역구 다중 선택 필터와 서울 지도 선택 UI를 "자리만"에서 "지금 디자인"으로 승격)

## 절차

1. v0 새 채팅에서 아래 "초기 프롬프트"를 그대로 붙인다. 모델은 기본값(v0)으로 둔다.
   화면별로 나눠 던지지 않는다 — 첫 생성이 가장 비싸므로 프롬프트를 고쳐서 처음부터
   다시 돌리는 일도 피한다.
2. 미리보기에서 모바일 폭(360px)을 먼저 확인한다. 아래 경로로 상태별 화면을 본다.
   - `/` 홈, `/announcements` 목록, `/announcements/6638` 상세, `/subscribe` 구독(로그인)
   - `/announcements?state=empty` 빈 상태, `?state=loading` 스켈레톤, `?state=error` 오류
   - `/announcements?district=중랑구,관악구` 지역구 2개 선택 상태(칩·지도 강조·결과 요약)
   - `/announcements/0` 404, `/subscribe?state=guest` 비로그인
3. 결과를 보고 "후속 프롬프트"로 톤·레이아웃을 다듬는다. 한 턴에 한 가지만 요청한다.
   이 단계에서 확정할 것은 색·타이포·간격·컴포넌트 모양이며, 기능은 건드리지 않는다.
4. 확정된 결과를 Code 탭에서 복사하거나 Download ZIP으로 받는다. v0의 GitHub 연동
   push는 쓰지 않는다(기존 구조와 달라 수동 이식이 맞다). Step별로 코드를 가져온다.
   - **Step a**: shadcn/ui 초기화(ADR 016), `globals.css`의 `@theme` 토큰, Pretendard 폰트,
     헤더·푸터 컴포넌트, 루트 레이아웃
   - Step b: 홈, 목록(카드·필터바·페이지네이션·빈 상태·스켈레톤)
   - Step c: 상세(헤더·필드 표·첨부·본문·원본 링크·404)
   - Step d: 구독(로그인 유도·계정 표시·채널 토글·Sprint 3 필터 자리)
5. 이식할 때 기존 컴포넌트의 구조와 시맨틱은 유지하고 `className`과 마크업 껍데기만
   바꾼다. 기존 E2E 셀렉터가 깨지면 테스트를 함께 갱신한다. 샘플 데이터 파일과
   `?state=` 미리보기 분기는 이식하지 않는다. 지역구 필터·지도 컴포넌트는 Step b에서
   마크업만 가져오고 실제 필터링 동작과 지도 path 데이터는 Sprint 3에서 붙인다.

## 서비스
서울시 청년안심주택 모집공고 사이트를 주기적으로 크롤링해 새 공고가 올라오면
구독자에게 웹 푸시·이메일로 알려주는 서비스입니다. 사용자는 알림을 받고 폰에서
링크를 열어 공고를 확인하는 경우가 가장 많습니다. 대상은 20~30대 청년이며, 주거
정보를 다루므로 신뢰감 있고 차분한 톤이어야 합니다. 화려한 마케팅 사이트가 아니라
"공고를 빠르고 정확하게 읽는 도구"입니다.

## 기술 제약 (반드시 지켜 주세요)
- Next.js App Router + React 19 + Tailwind CSS v4. Tailwind v4의 CSS-first 방식
  (`@import 'tailwindcss'` + `@theme`)으로 색·폰트 토큰을 globals.css에 정의해 주세요.
  토큰 이름은 역할 기준(primary, surface, muted, border, danger 등)으로 짓고, 화면
  코드에서는 `bg-blue-600` 같은 원색 클래스 대신 토큰 클래스만 쓰세요.
- shadcn/ui를 사용해 주세요(Tailwind v4 + `@theme inline` 방식). 컴포넌트는 실제로
  쓰이는 것만 추가하고(Button, Badge, Switch, Skeleton 정도), 필요 없는 컴포넌트를
  미리 깔지 마세요. 아이콘은 lucide-react, 화면당 2~3개 이내로 최소만.
- `cn()` 유틸리티는 `@/lib/utils/cn`에서 import합니다(`@/lib/utils`가 아님).
- 표시 전용 컴포넌트는 서버 컴포넌트로 만들 수 있게 useState·onClick 없이 작성해
  주세요. 상호작용이 필요한 곳은 아래에 명시한 토글 스위치만입니다.
- 라이트 모드만 디자인합니다. 다크 모드는 만들지 마세요.
- 모바일 우선. 360px 폭에서 먼저 완성하고 1280px까지 자연스럽게 넓어지게 해 주세요.
  본문 최대 폭은 약 672px(max-w-2xl)입니다.
- 한국어 UI. 본문 폰트는 Pretendard Variable 하나만 씁니다. 폰트 파일을 추가하거나
  CDN에서 불러오지 말고, `--font-pretendard` CSS 변수(폴백 system-ui)만 선언해서
  쓰세요. 실제 폰트는 이식 시 next/font/local로 주입합니다. 모노스페이스 폰트는 쓰지
  않습니다.
- 접근성: 텍스트 대비 WCAG AA 이상, 키보드 포커스 링이 보여야 하고, 필터 칩의
  선택 상태는 색만이 아니라 형태로도 구분되어야 합니다.

## 배지 규칙 (모든 화면 공통)
- 유형 배지(공공/민간)는 채도 낮은 채움 배경 + 진한 글자. 공공과 민간의 색을 구분합니다.
- 모집 배지(최초모집/추가모집)는 외곽선만 쓰고 배경은 없습니다. 유형 배지보다 위계가
  낮아야 합니다.
- 두 배지 모두 원색 강조를 피하고 본문 톤 안에 머물게 해 주세요.

## 화면 1 — 홈 (/)
서비스 한 줄 소개와 두 개의 진입점 [공고 목록 보기] [알림 받기]. 그 아래에
"최근 공고" 3건 미리보기(화면 2의 카드 재사용, 샘플 1~3번). 히어로 이미지 없이
텍스트와 여백으로 구성합니다.

## 화면 2 — 공고 목록 (/announcements)
- 제목 "공고 목록", 그 아래 결과 요약 한 줄 (예: "전체 6건", "조건에 맞는 공고 5건").
- 필터바 1단: 두 줄의 칩 그룹(단일 선택).
  - 유형: [전체] [공공] [민간]
  - 모집: [전체] [최초모집] [추가모집]
  각 칩은 링크(<a>)이고, 선택된 칩은 aria-current="true"인 <span>입니다.
- 필터바 2단 — 지역구 필터 (아래 "지역구 필터" 섹션 참고). 1단과 시각적으로 같은 칩
  언어를 쓰되, 다중 선택이라는 점이 드러나야 합니다(선택된 칩에 체크 표시 등 형태 차이).
- 결과 요약 줄은 선택된 지역구를 반영합니다. 예: "중랑구, 관악구 · 조건에 맞는 공고 2건".
- 카드 리스트(<ul>/<li>, 카드 전체가 상세로 가는 링크):
  - 상단 배지 2개: 유형, 모집 (위 배지 규칙).
  - 제목 (2줄까지 표시 후 말줄임 — 샘플 6번으로 확인).
  - 위치 한 줄: "자치구 · 단지명". 둘 다 null이면 줄 자체를 생략합니다(샘플 1번).
  - 날짜 2개: "청약신청 2026-09-12", "게시 2026-09-05". 청약신청일이 더 중요합니다.
    applicationDate가 null이면 "청약신청 미정"으로 표기합니다(샘플 3번).
  - 마감 구분: applicationDate가 오늘(2026-09-07)보다 이전이면(샘플 4~6번) 카드 전체를
    한 단계 흐리게 하고 청약신청일 옆에 작은 텍스트 "마감"을 붙입니다. 상태 필드는
    없으니 날짜 비교만으로 표현하고, 별도 배지 색을 추가하지 마세요. null은 마감으로
    취급하지 않습니다.
- 페이지네이션: [이전] [1] [2] [3] … [다음], 현재 페이지 강조. 샘플은 1페이지지만
  3페이지 있는 것처럼 그려 주세요.
- 상태 분기(미리보기 전용, searchParams `state`로 구분):
  - `?state=empty`: "아직 등록된 공고가 없습니다." (필터가 걸려 있으면 "조건에 맞는
    공고가 없습니다.")
  - `?state=loading`: 카드 5개 스켈레톤.
  - `?state=error`: "공고를 불러오지 못했습니다." + [다시 시도] 버튼.

## 지역구 필터 (화면 2 안의 섹션, 컴포넌트 이름 DistrictFilter)
서울시 청년안심주택 공식 사이트의 "지도 검색"을 참고한 UI입니다. 왼쪽에 서울 자치구
지도, 오른쪽에 25개 자치구 칩이 있고, 지도의 구역을 눌러도 칩을 눌러도 같은 선택이
됩니다. 다중 선택이며 "초기화"로 전체 해제합니다.

- 구성: 섹션 제목 "지역구" + 선택 개수("2개 선택") + [초기화] 텍스트 링크(선택이 없으면
  숨김). 그 아래 지도(SeoulDistrictMap)와 칩 그룹(DistrictChips).
- 칩: [전체] + 25개 자치구 칩. 전체는 선택이 하나도 없을 때만 선택 상태입니다. 자치구
  칩은 여러 개가 동시에 선택될 수 있고, 선택된 칩은 배경색 + 앞에 작은 체크 아이콘으로
  구분합니다. 칩은 모두 링크(<a>)이며 누르면 그 구가 `?district=` 목록에 추가/제거된
  URL로 이동합니다(useState·onClick 없이 링크 href만 계산하세요). 칩 순서는 가나다순.
- 지도: `<svg viewBox="0 0 600 500">` 하나. 정확한 행정경계는 그리지 마세요 — 이식 시
